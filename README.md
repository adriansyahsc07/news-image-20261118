One image that sums up the world news of Wednesday 18 November 2026: a 1024×1024 infographic with the day's six biggest stories — US strikes on Iran's Qeshm Island and Iran's retaliation in the Gulf, Xi and Putin meeting in Shenzhen before the summit with Trump, Ukraine's second-day strike on the Crimea Bridge, Peltola's Alaska win giving Democrats a 56-44 Senate majority, the Congo Ebola outbreak passing 11,000 cases, and the US losing its measles elimination status after 26 years. The image is rendered by `gen_image.py` (Pillow, code-drawn text so nothing is garbled); `main.py` copies `entry.png` to the output directory, byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```
